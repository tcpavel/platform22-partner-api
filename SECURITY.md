# Безопасность

## Если токен утёк

Токен попал в репозиторий, лог, чат, скриншот или к постороннему человеку — считайте его скомпрометированным:

1. **Сразу сообщите** вашему менеджеру Platform22 по рабочему каналу. Укажите контур (тестовый или боевой) и первые 8 символов токена — **не весь токен**.
2. Мы отключим токен. Запросы с ним начнут получать `403`.
3. Мы выпустим новый токен и передадим его по защищённому каналу.

Не создавайте для этого issue: репозиторий публичный.

## Как хранить токен

- В хранилище секретов (Vault, AWS Secrets Manager, секреты CI) или в переменной окружения — **не в коде**.
- Тестовый и боевой токены — разные. Не используйте боевой токен для отладки.
- Доступ к боевому токену — только у системы, которая отправляет сигналы.

## Уязвимость в API

Если вы нашли уязвимость в API Platform22, сообщите о ней вашему менеджеру напрямую, не публикуя деталей. Мы ответим и сообщим, когда исправим.
