# Changelog

Изменения API сигналов для партнёров. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Обратно совместимые изменения (новые необязательные поля, новые значения `reason`) выходят в рамках `v1`. Несовместимые — только в новой версии пути (`/partner/v2/…`), и `v1` при этом продолжает работать.

## [1.0.0] — 2026-09-29

### Добавлено

- `POST /partner/v1/positions/open` — открытие позиции и долив (`averaging: true`).
- `POST /partner/v1/positions/close` — закрытие позиции.
- Авторизация по токену партнёра (`Authorization: Bearer`), отдельному для тестового и боевого контура.
- Песочница `https://api-dev.pf22.ru` с тестовыми стратегиями `short-01` и `short-02`.
- Лимит — 120 запросов в минуту на токен.
